## 3. Deep-Dive: Avatar 3D Rig (`Avatar_Boy_Gun_AetherShadow`)

### 3.1 Description & Skeletal Hierarchy
The 3D model used in the avatar viewer (`Avatar_Boy_Gun_AetherShadow`) is a 243-bone hierarchical humanoid rig featuring:
- Full dual-arm skeletal articulation: Clavicles, Shoulders, Elbows, Forearms, and Wrists.
- High-fidelity 5-finger articulated bone structure per hand (Thumb, Index, Middle, Ring, Pinky with Proximal, Intermediate, and Distal phalanges).
- Articulated spine, neck, and head bones for signing posture and non-manual markers.
- Dual-eye gaze and jaw nodes for facial affect.
- Pre-bound vertex skinning configured for real-time WebGL rendering via Three.js `FBXLoader`.

### 3.2 Intellectual Property & Licensing Analysis
- **Copyright Holder:** miHoYo Co., Ltd. / COGNOSPHERE PTE. LTD. (HoYoverse).
- **Status:** The model mesh, rig, and diffuse textures are proprietary character assets from the video game *Genshin Impact*.
- **Fan-Content & Non-Commercial Policy:** HoYoverse publishes Overseas Fan-Made Merchandise and Content Guidelines permitting non-commercial fan creations and academic/research demonstrations. However:
  - Distributing raw 3D game models directly within a public GitHub repository violates GitHub Terms of Service regarding intellectual property and may trigger automated DMCA takedowns against the entire repository.
- **Decision & Architecture:**
  - `Avatar_Boy_Gun_AetherShadow/` is explicitly listed in `.gitignore` and **must never be committed to public Git branches**.
  - A dedicated setup script (`setup/download_models.ps1`) verifies the presence of the model on the local device, validates its SHA-256 checksum, provides clear instructions for user acquisition, and provides an automatic fallback cube/rig check so that headless validation tests run seamlessly even without the proprietary binary.

## 4. ISL Sign Motion Library Provenance

### 4.1 Linguistic Origins
The 586 signs stored in `signs/*.json` conform to **Schema 2.0.0** and represent lexical signs of Indian Sign Language (ISL). The motions, orientations, handshapes, and locations are synthesized based on:
1. **ISLRTC (Indian Sign Language Research and Training Centre)** 10,000-word published Sign Language Dictionary.
2. **Spreadthesign ISL Corpus** for regional variants across Delhi, Mumbai, and Bangalore deaf communities.
3. **Stokoe / HamNoSys Notation System:** Converted into Euler rotation sequences ($XYZ$ bone space) and Three.js normalized coordinate trajectories.

### 4.2 Schema 2.0.0 Guarantee
Every sign file includes:
- `schema_version`: `"2.0.0"`
- `sign_name`: Unique lowercase token identifier.
- `metadata`: Provenance, hand preference, two-handed flag, duration, and phonological description.
- `keyframes`: Array of normalized timestamps ($0.0 \dots 1.0$) with exact bone rotation angles in degrees or radians for 40+ skeletal joints.
