## 1. Reviewer Instructions & Evaluation Protocol

Thank you for participating in the linguistic validation of our automated ISL Accessibility Translator. The goal of this review is to evaluate whether the 3D avatar "Aether" produces natural, intelligible, and grammatically authentic Indian Sign Language.

### How to Review an Avatar Sign:
1. Open the avatar inspection viewer at `http://127.0.0.1:8000/index.html`.
2. Select a sign from the library dropdown (or enter a sentence in the test field).
3. Observe the avatar from both Front View ($0^\circ$) and Profile View ($45^\circ$).
4. Complete the 5-point evaluation rubric below.

---

## 2. 5-Point Linguistic Evaluation Rubric

| Criterion | 1 (Unacceptable) | 3 (Acceptable with Revisions) | 5 (Authentic ISL) |
| :--- | :--- | :--- | :--- |
| **1. Handshape (Chereme)** | Incorrect fingers extended; unrecognizable | Minor finger angle error; recognizable | Authentic ISL handshape matching ISLRTC |
| **2. Location (Tab)** | Incorrect signing region (e.g., chest vs temple) | Slight displacement but within valid zone | Exact anatomical placement |
| **3. Movement (Sig)** | Unnatural trajectory; mechanical jerkiness | Correct direction with minor timing flaws | Fluid, natural movement stroke |
| **4. Orientation (Dez)** | Palm facing wrong direction ($180^\circ$ inversion) | Slight tilt ($< 30^\circ$) | Exact palm and wrist orientation |
| **5. Natural Reset** | Freezes awkwardly midway through gesture | Resets abruptly without ease curve | Smooth return to neutral signing space |
