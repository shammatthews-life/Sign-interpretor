======================================================================
ISL ACCESSIBILITY TRANSLATOR — SIGNS DIRECTORY
======================================================================

This directory is the local storage location for validated Indian Sign
Language (ISL) lexical sign visual assets.

OFFICIAL RESOURCE POLICY:
1. Reference Source: Official Indian Sign Language Research and Training
   Centre (ISLRTC) materials.
2. Do NOT download random Google Images or unverified sign images.
3. Do NOT use American Sign Language (ASL) images.
4. Do NOT generate synthetic AI hand images as substitutes.
5. All image additions must be documented in data/sign_dictionary.json
   with source metadata and remain "verified": false until checked against
   official ISL linguistic references.

CONTROLLED VOCABULARY FILENAMES (13 Concepts):
- hello.jpg
- thank_you.jpg
- good.jpg
- morning.jpg
- evening.jpg
- how.jpg
- you.jpg
- help.jpg
- me.jpg
- water.jpg
- tomorrow.jpg
- rain.jpg
- please.jpg

GRACEFUL FALLBACK (MISSING IMAGES):
If any image file is missing, the application does NOT crash.
Instead, a clean placeholder card ("SIGN IMAGE NOT ADDED YET") is dynamically
rendered with the sign's gloss name.
